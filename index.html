Programming Tools

I created these Programming Tools in ChatGPT when I first started learning programming to give myself interactive learning tools to better understand how:

  1. Everyday numbers are represented in binary code, and how higher ranges of numbers are accessible by adding additional bytes.
  2. ASCII characters are represented by binary code.
  3. HTML colors are created through hexadecimal values.

Designed to work on any computer or mobile device.
